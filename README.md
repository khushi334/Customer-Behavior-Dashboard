# Customer-Behavior-Dashboard
An end-to-end Customer Behavior & Sales Analytics Dashboard built using Python, PostgreSQL, and Power BI.
The project focuses on cleaning customer data, querying it using SQL, and creating an interactive dashboard to analyze customer behavior, sales, revenue, shipping preferences, and subscription status.

🚀 Project Overview

This project follows a complete data analytics workflow:

Raw Data → Python Data Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard

The final Power BI dashboard provides an interactive view of:

Customer count

Average purchase amount

Average review rating

Revenue by product category

Sales by product category

Revenue by age group

Sales by age group

Subscription status

Shipping type preferences

Gender-based filtering

📂 Project Workflow

1. Data Cleaning using Python

The raw customer dataset was cleaned and prepared using Python.

Key tasks included:

Handling missing values

Removing duplicate records

Checking data types

Cleaning categorical columns

Preparing the dataset for database analysis

Exporting the cleaned data for PostgreSQL

2. Data Analysis using PostgreSQL

The cleaned dataset was loaded into PostgreSQL.

SQL queries were used to analyze:

Customer statistics

Category-wise sales

Category-wise revenue

Age-group performance

Subscription distribution

Customer behavior patterns

3. Dashboard Development using Power BI

The analyzed data was connected to Power BI to build an interactive dashboard.

The dashboard contains:

KPI cards

Donut chart

Category-wise column charts

Age-group comparison charts

Interactive slicers

▶️ How to Run the Project

Step 1: Clone the repository

git clone https://github.com/your-username/Customer-Behavior-Dashboard.git
cd Customer-Behavior-Dashboard

Step 2: Run the Python notebook

Open the notebook from the python/ folder and run the data-cleaning steps.

Step 3: Load the cleaned data into PostgreSQL

Create a PostgreSQL database and import the cleaned dataset.

Update the database connection details according to your local PostgreSQL setup.

Step 4: Run SQL queries

Open the SQL file from the sql/ folder and execute the queries in PostgreSQL.

Step 5: Open the Power BI dashboard

Open:

powerbi/Customer_Behavior_Dashboard.pbix

Update the PostgreSQL connection if required and refresh the data.
